Tải về 1 file .zip chứa toàn bộ dữ liệu. Tên file có ngày giờ xuất, ví dụ study-planner-backup_DD-MM-YYYY_HH-mm-ss.zip.

⬆ Nhập dữ liệu (Import)

Chọn file .zip đã xuất trước đó. Toàn bộ dữ liệu hiện tại sẽ được thay bằng dữ liệu trong file. Máy chủ tự lưu lại 1 bản sao của dữ liệu cũ trước khi nhập.
