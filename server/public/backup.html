Sao lưu dữ liệu

Toàn bộ dữ liệu (bài tập, lịch học, phần thưởng, điểm, file đính kèm…) được lưu trên máy chủ. Trang này dùng để tải bản sao lưu về máy hoặc khôi phục từ bản sao lưu.

⬇ Xuất dữ liệu (Export)

Tải về 1 file .zip chứa toàn bộ dữ liệu. Tên file có ngày giờ xuất, ví dụ study-planner-backup_05-11-2026_14-30-00.zip.

Tải bản sao lưu (.zip)

⬆ Nhập dữ liệu (Import)

Chọn file .zip đã xuất trước đó. Toàn bộ dữ liệu hiện tại sẽ được thay bằng dữ liệu trong file. Máy chủ tự lưu lại 1 bản sao của dữ liệu cũ trước khi nhập, nên có thể khôi phục lại nếu cần.

🗂 Bản sao lưu tự động trên máy chủ

Máy chủ tự tạo 1 bản mỗi ngày và 1 bản trước mỗi lần nhập dữ liệu.
